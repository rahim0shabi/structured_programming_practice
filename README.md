# structured_programming_practice
This is a repository that contains structured programming practice exercise

## Exercise 1-basic_output 
Description:This is a simple C program that asks the user to enter two integers, adds them together, and displays the sum.
How It Works;The program uses three integer variables:number1 – stores the first integer,number2 – stores the second integer,
 ,sum – stores the result of adding the two integers.The statement sum = number1 + number2;` performs the addition, and the result is displayed using `printf`.Source:Deitel & Deitel.

## Exercise 2-IPO
Description:This is a simple C program that asks the user to enter two integers and performs basic arithmetic operations on them: addition, multiplication, subtraction, division, and finding the remainder.How It Works:The program stores two integers in `num1` and `num2`. It then calculates and displays their sum, product, and difference. Before calculating the quotient and remainder, it checks whether the second integer is zero. If it is not zero, the program performs integer division and calculates the remainder. If it is zero, it displays a message explaining that the quotient and remainder cannot be calculated.Source:Deitel & Deitel.

## Exercise 3-decisions
Description :A C program that determines whether an integer entered by the user is even or odd. How It Works; The program asks the user to enter an integer. It uses the modulus ("%") operator to check the remainder when the number is divided by 2. A remainder of 0 means the number is even; otherwise, it is odd.Source:Dietel & Dietel

## Exercise 4-basic loop
Description:A C program that displays the numbers from 1 to 10 along with their squares, cubes, and fourth powers.How It Works;The program uses a "for" loop to count from 1 to 10 and displays each number, its square, cube, and fourth power in a tabular format.Source:Dietel & Dietel

## Exercise 5-loop + calculation
Description:A C program that calculates and displays the factorials of the numbers from 1 to 5.How It Works;The program uses a "for" loop to calculate each factorial. The factorial value is updated by multiplying it by the current number, then the number and its factorial are displayed in a table.Source:Dietel & Dietel
