## Exercise 1-basic_output 
Description:This is a simple C program that asks the user to enter two integers, adds them together, and displays the sum.
How It Works;The program uses three integer variables:number1 – stores the first integer,number2 – stores the second integer,
 ,sum – stores the result of adding the two integers.The statement sum = number1 + number2;` performs the addition, and the result is displayed using `printf`.Source:Deitel & Deitel.
